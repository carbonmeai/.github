# Contributing

Thanks for helping. This guide applies to every repository in the [carbonmeai](https://github.com/carbonmeai) organization that does not have a contributing guide of its own. [danwo](https://github.com/carbonmeai/danwo/blob/main/CONTRIBUTING.md) has its own, with its setup and checks.

By taking part you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md). Security problems go through the [security policy](SECURITY.md), not public issues.

## Issues

- Search the open and closed issues first; add to an existing one rather than opening a second.
- For a bug, say what you did, what you expected and what happened instead, with the versions involved and the smallest steps that reproduce it.
- For an idea, say what problem it solves before how.

## Pull requests

- For anything larger than a small fix, open an issue first so we can agree on the approach before you spend time on it.
- Keep a pull request to one change, and follow the code around it: its naming, style and comments.
- Run the repository's checks and tests before you push, and add a test for what you fixed or added.
- Write commit messages as [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/), such as `fix: …` or `docs: …`.

## Forks

Some repositories here are forks we keep in step with their original project. A change that helps everyone belongs upstream; open it there, and we will pick it up.
