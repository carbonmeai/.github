## Carbonme

We build software for teams whose work runs on documents, and the tools to test it.

### [Carbonme](https://carbonme.ai)

Document work, automated, with every answer traced to its source. Carbonme automates
document-heavy workflows end to end for finance, banking, insurance, real estate, legal and
compliance teams.

### [dánwò](https://danwo.dev) · open source

The end-to-end testing framework for web and mobile apps. danwo drives your app through its UI
like a user, simulates the real services it calls, then introduces faults one at a time to show
you what breaks.

```sh
npx @danwo/cli init
```
