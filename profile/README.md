## Carbonme

We build **dánwò** (danwo), the open-source end-to-end testing framework for web and mobile apps.
It drives your app through its UI like a user, simulates the real services it calls, then
introduces faults one at a time to show you what breaks.

```sh
npx @danwo/cli init
```
